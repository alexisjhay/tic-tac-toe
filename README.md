<h1>Tic-Tac-Toe</h1>

<p>A Tic-Tac-Toe game built with HTML, CSS, and JavaScript as part of <a href="https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe">The Odin Project</a> curriculum.</p>

<h2>Features</h2>
<ul>
  <li>Two-player gameplay</li>
  <li>Win and draw detection</li>
  <li>Score tracking</li>
  <li>Restart and new game options</li>
  <li>Player name input</li>
</ul>

<h2>What I Learned</h2>
<ul>
  <li>Factory functions and the module pattern</li>
  <li>Closures and game state management</li>
  <li>DOM manipulation and event handling</li>
  <li>Managing player turns and game logic</li>
</ul>

<h2>Technologies</h2>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
